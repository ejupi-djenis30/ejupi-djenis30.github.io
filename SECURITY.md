# Security policy

This repository serves static HTML, CSS, images and crawler metadata. It does
not accept user input or run application code in the browser.

Please report a suspected vulnerability privately to
[info@ejupilabs.com](mailto:info@ejupilabs.com). Do not include secrets or
personal data in a public issue.

The machine-readable vulnerability-reporting policy is published at
[`.well-known/security.txt`](https://ejupi-djenis30.github.io/.well-known/security.txt).
